# Tessal — Electrical & Computer Engineering Portfolio

Live personal engineering portfolio of **Tessal** (Lê Hoàng Phúc Anh), showcasing systems built at the boundary of physical reality and digital silicon.

## 🚀 Overview

This website is built with a clean, subtractive engineering aesthetic — featuring zero card chrome, pure vector schematic blueprints, live biomedical signal telemetry, and full bilingual support (English & Vietnamese).

## 🔬 Featured Engineering Works (Ranked by Complexity)

1. **[Custom CoreXY Klipper 3D Printer](https://github.com/tessal-hub/embedded_linux_with_luckfoxpico)** — High-speed scratch-built CoreXY 3D printer running Klipper Linux host on a Luckfox Pico Max (ARM Cortex-A7 @ 1.2 GHz), dual synchronized H-belts, 1 Mbps CAN bus toolhead, silent TMC2209 stepping, and ADXL345 input shaping resonance tuning.
2. **[NEMA 6-Axis Robotic Arm](https://github.com/tessal-hub/robotic_arm)** — ESP32-S3 drawing arm pairing 6 AS5600 magnetic encoders with a 50 kHz Q32.32 DDA step engine, analytical Modified DH kinematics, and calibrated work planes.
3. **[High-Speed ESP32 Benchmark Line Follower](https://github.com/tessal-hub/line-follower)** — Autonomous racing robot with an 8-channel optical array through a high-speed CD74HC4067 analog MUX, dual DRV8871 20 kHz PWM drivers, quadrature encoders, and a deterministic 1 kHz hard real-time PID loop.
4. **[ESP32-S3 ECG Monitor & Touch Companion](https://github.com/tessal-hub/ecg_monitor)** — 480×320 ILI9488 touchscreen telemetry platform with real-time continuous Lead-II ECG plotting, statistical metrics, zero-flicker double-buffering, and an interactive state-driven desktop mascot.
5. **[STEM AI Platform](https://github.com/tessal-hub/stem_ai)** — Desktop TinyML learning environment streaming 6-axis IMU frames from an ESP32 wand at 50 Hz for few-shot gesture recognition and one-click C99 deployment.
6. **[360° LED Matrix & Android BLE Controller](https://github.com/tessal-hub/leding)** — Spatial 360° smart LED lamp and native Kotlin Android app communicating over Nordic UART Service (NUS) BLE with sub-50ms latency and real-time IMU tilt telemetry.
7. **[DSP-PPG Analyzer](https://github.com/tessal-hub/DSP-PPG)** — PyQt6 desktop biomedical analyzer for Excel PPG captures with motion-artifact validation, configurable IIR/FIR filter topologies, and physiological metrics.
8. **[STM32 12-Channel I/O Monitor](https://github.com/tessal-hub/appdts)** — PyQt5 UART workbench for twelve STM32 outputs and twelve live inputs at 115200 baud with a built-in virtual hardware simulator.

## 🛠️ Tech Stack

- **Hardware & Silicon**: Luckfox Pico Max (Rockchip RV1106), ESP32 (S3/C3), STM32 (ARM Cortex-M), CAN Bus Toolheads, TMC2209 Drivers, AS5600 Magnetic Encoders, ILI9488 Touch & Fast I²C OLEDs.
- **Firmware & Embedded**: Embedded Linux, Klipper Host, Input Shaping (ADXL345 Resonance Tuning), C / C++ (C++17/20, FreeRTOS, Bare-Metal), Hard Real-time PID & Fixed-point DDA.
- **Software & Wireless**: Kotlin (Android Jetpack, Nordic UART BLE), Python (PyQt6, scipy.signal, TinyML), Analytical Kinematics (Modified DH).
- **Frontend Architecture**: Pure HTML5, CSS3 Custom Properties, Vanilla JavaScript (ES6+), Inline SVG Vector Blueprints, Canvas Oscilloscopes, WCAG 2.1 AA accessible, Zero heavy asset dependencies.
