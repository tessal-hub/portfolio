# Tessal — Electrical & Computer Engineering Portfolio

Live personal engineering portfolio of **Tessal** (Lê Hoàng Phúc Anh), showcasing systems built at the boundary of physical reality and digital silicon.

## 🚀 Overview

This website is designed with a **Subtractive Studio** aesthetic inspired by Kenya Hara ("White") and Pentagram architectural restraint — featuring zero card chrome, pure vector schematic blueprints, live biomedical signal telemetry, and full bilingual support (English & Vietnamese).

## 🔬 Featured Engineering Works

1. **[NEMA 6-Axis Robotic Arm](https://github.com/tessal-hub/robotic_arm)** — ESP32-S3 drawing arm pairing 6 AS5600 magnetic encoders with a 50 kHz Q32.32 DDA step engine, analytical Modified DH kinematics, and calibrated work planes.
2. **[STEM AI Platform](https://github.com/tessal-hub/stem_ai)** — Desktop TinyML learning environment streaming 6-axis IMU frames from an ESP32 wand at 50 Hz for few-shot gesture recognition and one-click C99 deployment.
3. **[DSP-PPG Analyzer](https://github.com/tessal-hub/DSP-PPG)** — PyQt6 desktop biomedical analyzer for Excel PPG captures with motion-artifact validation, configurable IIR/FIR filter topologies, and physiological metrics.
4. **[ESP32-S3 ECG Monitor & Touch Companion](https://github.com/tessal-hub/ecg_monitor)** — 480×320 ILI9488 touchscreen telemetry platform with real-time continuous Lead-II ECG plotting, statistical metrics, and an interactive state-driven desktop mascot.
5. **[STM32 12-Channel I/O Monitor](https://github.com/tessal-hub/appdts)** — PyQt5 UART workbench for twelve STM32 outputs and twelve live inputs at 115200 baud with a built-in virtual hardware simulator.
6. **[High-Speed ESP32 Benchmark Line Follower](https://github.com/tessal-hub/line-follower)** — Autonomous racing robot with an 8-channel optical array through a high-speed CD74HC4067 analog MUX, dual DRV8871 20 kHz PWM drivers, quadrature encoders, and a hard real-time PID loop.
7. **[360° LED Matrix & Android BLE Controller](https://github.com/tessal-hub/leding)** — Spatial 360° smart LED lamp and native Kotlin Android app communicating over Nordic UART Service (NUS) BLE with sub-50ms latency and real-time IMU tilt telemetry.

## 🛠️ Tech Stack

- **Frontend**: Vanilla HTML5, CSS3 Custom Properties, JavaScript (ES6+).
- **Graphics & Vectors**: Pure Inline SVG blueprints & HTML5 Canvas oscillators (Zero heavy asset dependencies).
- **Typography**: DM Serif Display, Inter, JetBrains Mono.
- **Internationalization**: Zero-dependency client-side EN/VI translation engine with localStorage persistence.
- **Accessibility**: WCAG 2.1 AA compliant, full keyboard navigation, `prefers-reduced-motion` detection.
